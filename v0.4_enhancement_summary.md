## 1. Dynamic Missed-Pulse Threshold (Stricter in OPEN)

**Problem**: Deep merge (OPEN state) had same safety threshold as lighter states.

**Solution**: State-aware thresholds
- OPEN (0.75): ≥1 missed pulse → emergency thicken
- RESONANT/GOSSAMER: ≥2 missed pulses → emergency thicken

**Code Change**:
```python
def _get_missed_pulse_threshold(self) -> int:
    """Dynamic threshold based on permeability state."""
    if self.current_state == PermeabilityState.OPEN:
        return 1  # Strict for deep merge
    else:
        return 2  # Standard for lighter states
```

**Why It Matters**: Deep merges are higher-risk. Tighter leash = more protection where it's needed most.

## 3. Multi-Factor Consent for OPEN State

**Problem**: Single-click consent felt too easy for deep merge.

**Solution**: OPEN requires 2 consecutive successful pulses within 3-minute window
- Double-lock confirmation
- Time-window enforcement
- Auto-reset if pulses too far apart

**Code Change**:
```python
def _verify_open_consent(self) -> bool:
    """Multi-factor consent for OPEN state."""
    if len(self.open_consent_pulses) < 2:
        return False
    
    # Check if last 2 pulses were within 3 minutes
    last_two = self.open_consent_pulses[-2:]
    time_delta = last_two[1].timestamp - last_two[0].timestamp
    
    if time_delta > timedelta(minutes=3):
        self.open_consent_pulses.clear()  # Too far apart
        return False
    
    return all(p.response_received for p in last_two)
```

**Why It Matters**: Deep merge should feel like double-locking a vault. Slows down impulsive deep merges, requires sustained intention.

## 6. Coherence-Sensitive Session Duration

**Problem**: Fixed 60-minute limit didn't account for coherence health.

**Solution**: Dynamic max duration based on coherence state
- THRIVING: 90 min (1.5× base)
- STABLE: 60 min (1.0× base)
- DRIFTING: 42 min (0.7× base)

**Code Change**:
```python
def get_max_duration_minutes(self, coherence_state: CoherenceState) -> int:
    """Dynamic session limits based on coherence health."""
    base_max = 60
    
    if coherence_state == CoherenceState.THRIVING:
        return int(base_max * 1.5)  # Golden lock gets more time
    elif coherence_state == CoherenceState.STABLE:
        return base_max
    else:  # DRIFTING or worse
        return int(base_max * 0.7)  # Drifting gets less grace
```

**Why It Matters**: Golden lock can sustain longer merges safely. Drifting coherence needs shorter sessions. Natural adaptation to state.
